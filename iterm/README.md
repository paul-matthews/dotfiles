# iTerm2 Workspace Layouts

The `iterm-layout` CLI tool allows you to programmatically split, resize, color, and execute startup commands inside iTerm2 window/tab sessions. It is designed to configure your developer workspaces easily, supporting local configurations so you can use different layout behaviors (e.g. `jetski` vs `claude` CLI) on different machines.

---

## 1. Setup & Installation

The tool is completely self-contained and manages its own dependencies dynamically using the `uv` tool (transient python package runner).

1. Ensure `uv` is installed (handled by dotfiles `script/install` / `brew bundle`).
2. Run `script/bootstrap` to link your layout configuration.
3. Enable iTerm2 Python API:
   - Go to **iTerm2 > Settings > General > Magic**.
   - Check **Enable Python API**.

---

## 2. Configuration (`~/.iterm_layouts.yaml`)

The local configurations live in `~/.iterm_layouts.yaml` (which is symlinked from `iterm/iterm_layouts.yaml.symlink` and generated by the bootstrap script).

### Example Configuration:
```yaml
work:
  tab_color: [32, 100, 100]        # RGB color for the tab chrome (0-255)
  bg_color: [20, 35, 35]           # RGB color for session background
  split: horizontal                # split direction: horizontal or vertical
  panes:
    - size: 0.75                   # 75% height/width of total layout size
      command: jetski              # Startup command to run in pane 1
    - size: 0.25                   # Remaining 25% height/width
      command: ""                  # Leaving command empty opens a blank terminal

claude-dev:
  tab_color: [100, 50, 120]
  bg_color: [30, 20, 35]
  split: vertical
  panes:
    - size: 0.5
      command: claude
    - size: 0.5
      command: cd ~/src/dotfiles && git status
```

---

## 3. Usage

The `iterm-layout` executable is added to your shell `$PATH` and can be run globally:

```bash
# Setup a new tab in the current window and apply "work" layout
iterm-layout new work

# Apply "claude-dev" layout on the active pane in your current tab
iterm-layout apply claude-dev

# Open a new window and apply the layout
iterm-layout window work
```
